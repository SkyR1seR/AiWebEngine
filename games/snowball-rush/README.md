# «Нубик: Снежная гонка» / Noob: Snowball Rush

Новогодняя соревновательная гонка в блочной (воксельной) стилистике на движке aiWebEngine.
**Нубик** и 4 соперника-бота, которые выглядят как онлайн-игроки, катят перед собой снежные комья.
Ком растёт на снегу; большой ком пробивает ледяные стены с числом, тушит костры, ломает препятствия
и закрывает полыньи (становится мостом). Маленький ком разбивается о препятствия, тает на проталинах,
соли и у костров. Место 1–3 — уровень пройден.

Подробный дизайн и контракты модулей — в [DESIGN.md](DESIGN.md).

## Запуск и публикация

```bash
npm run dev                                   # http://localhost:5173/games/snowball-rush/
npm run export snowball-rush -- --playgama    # export/snowball-rush.zip с Playgama Bridge внутри архива
npm run smoke snowball-rush -- --playgama     # проверка сборки (headless Chrome, WebGPU и WebGL2)
node games/snowball-rush/tools/i18n.mjs       # собрать строки для перевода (tools/strings.json)
node games/snowball-rush/tools/i18n.mjs --check   # проверить словари lang/*.json
```

Платформа — **Playgama Bridge** (`aiwebengine/playgama`): одна сборка для Яндекс Игр, CrazyGames, Playgama,
VK, OK, GameDistribution и других. `playgama-bridge.js` кладётся в архив (внешние скрипты запрещены),
настройки рекламы и список покупок — в [playgama-bridge-config.json](playgama-bridge-config.json).

Управление: перетаскивание пальцем/мышью влево-вправо, клавиши A/D или стрелки, геймпад.

## Механики

- **Рост кома**: по снегу ком растёт (чем больше, тем медленнее), на льду — нет, но быстрее бег;
  проталины и соль растапливают ком, ускорители дают рывок.
- **Ледяные стены** с числом: если размер кома не меньше числа — стена ломается (и остаётся сломанной для всех),
  ком немного уменьшается. Иначе ком разбивается, а стена трескается (число уменьшается) — застрять нельзя.
- **Препятствия** появляются по одному: шипы и стены → ускорители → костры → полыньи (нужен большой ком — он станет
  мостом для всех) → сдвигающиеся подарки → маятники-леденцы → проталины/соль/лёд → сосульки → снегоуборщик.
  Перед первой встречей — карточка «Новое препятствие» с правилом.
- **Бонусы на трассе**: монеты, редкие кристаллы, подарки (щит, ускорение, +размер).
- **Бонусная зона** после финиша: стены x1.2 … x5 умножают награду.

## Сложность

Плавная кривая `1 − e^(−n/14)`: длина трассы, плотность и скорость препятствий, требования стен и полыней,
навык ботов растут постепенно. **Каждая неудачная попытка делает уровень легче** (та же трасса, но часть
препятствий убрана, требования ниже, боты медленнее) — до −50% сложности; игрок видит «Попытка 3 — уровень стал легче!».

## Обучение и открытие контента

- Первая гонка — обучение с подсказками Нубика и замедлением: руление, рост кома на снегу, число на стене,
  монеты, бонусные стены. Первую гонку Нубик выигрывает.
- Функции меню открываются по уровням: улучшения (1), гардероб и календарь (2), подарки-кейсы (3), магазин (4).
  Закрытые кнопки видны с замком и «Ур. N»; при открытии — окно «Открыто!», рука-подсказка и подарок:
  первое улучшение бесплатно, первый кейс бесплатно, скин «Нубик в шапке» в подарок.
- Реклама между гонками — только с 3-го уровня, предложения и покупки — после открытия магазина.

## Фейк-онлайн

Подбор соперников с никами, кубками, скинами и VIP-коронами, счётчик «Сейчас играют», эмоции и
сообщения ботов в гонке, редкие «отключения». Боты управляются ИИ с разным уровнем навыка и
мягкой «резинкой», чтобы гонки были напряжёнными.

## Мета и монетизация

- **Монеты** (мягкая валюта): за гонки и рекламу → улучшения (скорость, липкий снег, прочность кома,
  стартовый ком, магнит), обычные скины.
- **Кристаллы** (мета-валюта): даются понемногу (календарь, повышение лиги, редкие находки на трассе),
  основной источник — покупки. Тратятся на кейсы, редкие скины, выгодные предложения.
- **Кейсы-подарки**: Снежный (бесплатно за рекламу раз в 4 часа), Ледяной, Подарок Деда Мороза;
  рулетка, шансы выпадения, гарантия легендарки, компенсация дубликатов.
- **Скины**: Нубик и Нубик в шапке + 12 новогодних костюмов (Лыжник, Хоккеист, Пингвин, Эльф, Пряник,
  Снеговик, Олень, Снегурочка, Ледяной рыцарь, Дед Мороз, Йети, Щелкунчик) и 9 комов (Снежок, Мандарин,
  Леденец, Ёлочный шар, Гирлянда, Ледяной кристалл, Диско-шар, Золотой ком, Оливье); примерка за рекламу.
- **Временные предложения**: стартовый набор (48 ч после открытия магазина), «горячее предложение»
  (каждые 6 ч), Новогодний набор (1 декабря – 15 января, вне сезона — «Зимний набор»), предложение после поражений.
- **Реклама** (основной доход): межстраничная между гонками (с 3-го уровня, не чаще раза в минуту, не после
  первой гонки сессии), вознаграждаемая — x2 награды, бесплатный кейс, монеты в магазине, бесплатное улучшение,
  примерка скина, x2 в календаре.
- **Новогодний календарь**: 7 дней подарков.

### Покупки

ID товаров (уже в `playgama-bridge-config.json`; цены и названия задаются в кабинетах платформ):

| ID | Что даёт |
|---|---|
| `gems_60` | 60 кристаллов |
| `gems_330` | 330 кристаллов (+10%) |
| `gems_700` | 700 кристаллов (+20%) |
| `gems_1500` | 1500 кристаллов (+30%) |
| `gems_4000` | 4000 кристаллов (+50%) |
| `starter_pack` | стартовый набор: 300 кристаллов + скин «Ледяной рыцарь» + 3000 монет |
| `newyear_pack` | новогодний набор: скин «Дед Мороз» + «Золотой ком» + 800 кристаллов |
| `no_ads` | отключение межстраничной рекламы (постоянная покупка) |

Необработанные покупки начисляются при следующем запуске, `no_ads` восстанавливается автоматически.
Локально (localhost или `?testpay=1`) работает тестовый режим покупок.

## Языки

19 языков: русский, английский, украинский, турецкий, испанский, португальский, немецкий, французский,
итальянский, польский, нидерландский, японский, корейский, китайский, индонезийский, вьетнамский, хинди,
арабский, тайский (белорусский, казахский, узбекский и др. → русский). Язык берётся из платформы.
Код содержит русский и английский тексты, остальные — словари `lang/<код>.json` по английскому тексту,
загружается только словарь текущего языка.
